# Chinese serif font

Noto Serif SC, weights 400 and 600. Licensed under SIL OFL 1.1 (OFL.txt).
Source: https://fonts.google.com/noto/specimen/Noto+Serif+SC
License: https://github.com/google/fonts/tree/main/ofl/notoserifsc

The stylesheet uses unicode ranges to load only the subsets a page needs. All font requests stay on the site origin. English continues to prefer Times New Roman / Times.
