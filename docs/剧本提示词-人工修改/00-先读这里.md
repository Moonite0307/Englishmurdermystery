## 第 01 份花括号的意思

程序会在发送请求前填入：

| 占位符 | 填入内容 |
| --- | --- |
| {genre} / {genreRule} / {genreDesign} | 玩家选择的类型、类型简述及该类型的专属要求，见第 02 份 |
| {level} / {levelDesc} | 中考、高考、四级等学习目标和词汇范围说明 |
| {challenge} / {challengeDesc} | 简单、困难、地狱及对应英语句式要求 |
| {totalChars} / {npcCount} | 本局总人数 / NPC 人数 |
| {themeLine} / {bgLine} | 玩家输入的主题 / 背景，未填写则为“未指定” |
| {playerRole} | 从对应类型身份池中随机选出的身份方向 |
| {structureRule} | 难度对应的线索数、问题数和结构要求 |

建议保留这些占位符的英文拼写。第 03 份的 {scriptPlan} 是本局锁定底稿，{playerScript} 是玩家角色本，{coreVocab} 是本地词库分配的学习词汇。
