## 记录保存策略

游客的生词本、词汇复习、剧本档案和闯关进度只保存在当前文档内存中，不写入 localStorage 或 sessionStorage。刷新、重新进入或从浏览器返回缓存恢复游客页面时清空。主题选择与接口设置不属于游玩记录，继续保留。

账号记录使用按用户名隔离的缓存与原有云端同步。登录时只加载该账号缓存和远端记录，不合并游客临时记录；退出和登录失效时清空当前记录及相关界面，剧本档案也包含在清理范围内。退出前发送当前账号的记录快照，异步响应校验会话身份，不能把旧账号状态恢复到游客或新账号。升级时，仅在浏览器有既存账号凭据时将旧格式缓存迁移给该账号，无账号的旧记录清除。

新增测试覆盖游客旧缓存清理、不落盘、刷新与重新进入、页面缓存恢复、账号保存及重载、游客到登录的隔离、退出后的剧本清理、账号切换、旧账号迁移和登录失效清空。原有账号和游戏回归继续保留。本次仅修改本地，未推送或部署。

最终验证：账号与游戏回归 22/22 通过，静态构建及 git diff --check 通过。另修复登录弹窗延迟聚焦可能抢走密码输入焦点的问题。

## 2026-11-11：退出续玩与词卡自测

- 对话：去掉角色气泡的紫色内联背景，用浅色纸张 #f6efdf / 深色面板 #202c38，加金色左边线；头像、名字、词汇及查词浮层沿用棕金主题。日夜切换直接响应主题变量。
- 退出：游戏内侧栏只保留「退出」，弹窗提供「保留进度返回首页」「换剧本」「继续当前剧本」。本轮回复尚未完成时禁止保存和切换，完成后启用，避免异步回复写入另一局。
- 进行中：开局档案显示「本次未保存」，主动保存才显示「进行中」。在首页「玩过的剧本」点击档案，使用「继续玩」恢复。旧版没有完整存档的进行中记录不提供虚假继续入口。
- 存档：在原有账号 / 游客记录通道保存完整锁定剧本、系统与对话消息、任务证据 Map、去重 Set、搜证选项、三次提示计数、词汇覆盖、待回顾状态、已展开翻译与输入草稿。恢复时重新冻结原剧本，以结构化消息重建交互，不保存或注入 HTML，不重发开场、不重复收词或结算任务。上一次主动保存的检查点在续玩时保留，换剧本或通关时清理。
- 自测：两个词汇列表都说明用法；生词本增加待复习 / 已掌握 / 未掌握筛选。每次打开只展示英文词、音标和英文例句，中文释义与例句译文隐藏，词频排名移除。
- 答题：选认识后停留并揭示释义，归入已掌握；显示下一个 / 记错了。选不认识后揭示释义并归入未掌握；记错了修正同一次自测，归入未掌握，不重复累计复习次数。已掌握与未掌握均可反复打开自测，同一词在两个页面的掌握状态同步。
- 例句：优先使用已有英文例句，新出现的词补充真实 NPC 语境。旧词缺少例句时检索已有对话；无语境才显示通用英文学习句，不在打开词卡时等待模型生成。
- 数据：续玩仍遵守游客只在当前页面内存有效、刷新清空，账号才缓存并同步。云端合并按最新保存 / 复习时间保留状态，避免仅依赖开始时间或出现时间覆盖新进度。本次不改账号服务或部署配置。
